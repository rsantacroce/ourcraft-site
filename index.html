Ourcraft

A blocky world to build, explore and play together. Endless hills, forests, beaches and snowy mountains made of blocks, and they're all yours to dig, build and share.

How to play Get the game
Free & open source Mac · Windows · Linux iPad · Android No accounts, no ads

What you can do

Ourcraft is a sandbox: there's no single goal. Wander, build a castle, dig a cave, or invite friends and play a game together.

Endless worlds

Every world is different and goes on forever: plains, forests, deserts, snowy hills, mountains, caves, lakes and seas.

Build anything

Break and place blocks: stone, wood, glass, bricks, glowing lamps and bright paint colours. Fly in creative mode, or collect blocks in survival.

Play together

Friends on your home network can join your world in a couple of taps, or run a server to play over the internet. See each other build in real time and chat.

Splat Squad

A team game for 2 or more players: Red against Blue, four classes, paint gadgets and capture the flag. Cartoon paint, no blood.

Mods

New blocks, gadgets and whole game modes can be added as mods. Mods run in a safe sandbox and can't touch your files or the internet. Make your own.

On your device

Keyboard and mouse, gamepad, or touch: play on a computer, an iPad or an Android tablet.

Your worlds, saved

Keep as many worlds as you like. The game saves on its own, so nothing is lost when you stop playing.

Made for families

No sign-ups, no ads, no shop. Chat has a filter for rude words, switched on by default.

Get the game

Ourcraft is built from its source code. It takes a few minutes the first time and is quick after that. There are no download buttons yet.

On a computer

  1. Install Rust from rustup.rs.
  2. Download the game: 
    git clone https://github.com/rsantacroce/ourcraft
cd ourcraft
  3. Start it: 
    cargo run --release

Works on macOS, Windows and Linux. On Linux you may need a few extra packages for graphics and sound; see the manual.

On iPad or Android

iPad/iPhone: open mobile/ios/ourcraft_mobile.xcodeproj in Xcode on a Mac, pick your Apple account under Signing and press Run.

Android: run mobile/android/build.sh (needs the Android SDK and NDK) and install the APK it makes.

Run a server

cargo run --release -p ourcraft_server \
  --bin ourcraft-server -- --world world

Add --mode team_shooter for a Splat Squad server. More about servers.

Under the hood

For the curious and the grown-ups: Ourcraft is written in Rust with the Bevy game engine.

Fast blocky worlds

The world is made of 16×16×16 chunks, compressed in memory, turned into meshes on background threads with greedy meshing and soft corner shadows.

Fair multiplayer

The server decides what's real. Your own movement is predicted on your device, so it feels instant even on a slow connection, and corrected smoothly when needed.

Safe mods

Mods are WebAssembly programs run by wasmtime with no access to files or the network, and with limits on time and memory. The whole Splat Squad game is a mod. See the modding guide.
